# Hero animation prototype — chat → deal card

Throwaway prototype for the Hero product-visual slot on `/` (landing).
Concept = the **A + C mix** Ayush chose: real chat sentences flow in, the key
facts light up (signal), fly through the `//` transform seam, and build a
structured **Deal Card** on the right. Ends on Total + Documented ✓, then loops.

## What to look at
- Shown **in context**: mini-hero (headline + CTAs) above the animated frame, so
  it reads the way it will in the real hero.
- Palette / glass / aurora copied 1:1 from `src/app/globals.css` (raspberry
  `#e30b5d`, cotton-candy `#ffb7d5`, damson `#7a1638`).
- Type choice is deliberate: chat = sans (human), deal-card fields = **mono**
  (structured data). Reinforces "language → structured deal".
- Signature element = the `//` seam bloom as a plain phrase crystallises.
- Reduced-motion: renders the finished end-state, no movement.

Friday? · Seller → Net 30? · Buyer → Deal. → Total €1,200 · Documented ✓
